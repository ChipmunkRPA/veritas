# Paid image flow: automatic checks pass; conclusion scope needs correction

Five isolated full image-analysis flows completed with real local models and
production HTTP, queue, evidence and report paths. Stripe transport alone was
simulated: USD 9.99, with the existing risk acknowledgement. Neither an unpaid
checkout nor its unpaid callback created analysis work or loaded models. The
paid entitlement was verified before every observed weight load and regional or
legacy forward. No live payment, deployment, outreach or workflow occurred.

The full enabled set was used: 17 checks in legacy mode and 18 in candidate
mode. All outcomes were recorded; inapplicable checks remained explicit. Both
region checks succeeded on the supported PNG pair. The candidate made two native
forwards; the legacy check made four forwards across paired modes. The authored
undersized image remained inconclusive. This was engineering verification on a
previously consumed source, not a fresh accuracy or generator-generalization test.

API evidence and JSON export matched exactly. All declared source crops,
overlays and masks were served and hash-verified. Each report snapshot captured
the same evidence set. The candidate edit produced an additional localization
packet; its normal browser view loaded the source crop and measured mask, with
no script errors or exposed private model names. Reports also omitted model
names and examination/sign-off controls. All seven monitored steps passed
(preparation, five flows, seal); peak sampled worker-tree RSS was 4,348,690,432
bytes. CPU float32, two CPU threads, 4096 MiB model-manager budget, one queue
worker; MPS and higher concurrency were not qualified.

## Material issue exposed by the complete flow

The edited photograph received **“Leaning towards original content in the
assessed scope” at 96.6%**, while the new regional evidence highlighted the edit.
Its paired original received 97.7%. The underlying whole-image synthesis
estimates matched exactly between modes, as required for a zero-weight regional
check. That numerical agreement is not sufficient for product admission: the
generic headline and original-file wording overstate what was checked. A mostly
real photograph can contain an AI-generated local edit that those whole-image
classifiers miss. A raw regional response cannot simply be turned into a new AI
confidence percentage either.

The local default remains unchanged. The next correction must distinguish the
whole-image synthesis estimate from unresolved localized editing, explicitly
scope any percentage, and remove broad original-file wording from this case in
the app, PDF and JSON. Preserve these original results, all five reports and the
frozen code; validate the correction separately without refitting or retuning.
Existing PDFs remain immutable. PDF visual review and the dedicated shared-pixel
view remain outstanding, alongside further image generators/ordinary-edit
controls and the broader audio, video and writing work. The goal is not complete.
