# Production readiness of release 2.1.1

**State on 11 October 2026: production ready.** Release 2.1.1 is production ready when it meets the seven
criteria the supervising team set on 29 September 2026 (decision D-54 in `docs/v2/01-DECISIONS.md`, quoted in each
section below). All seven are met on the code of `a876a43a`, and the tag `v2.1.1` is on the commit that holds
this page. This page says, for each criterion, what has been measured, by whom,
on which commit, and what is still missing. A row is not called met on an intention: where something was read and not
run, or run on an earlier commit, it says so.

The review of v0.3 that stood here is kept as a historical record in
[`docs/history/production-readiness-v0.3.md`](history/production-readiness-v0.3.md).
