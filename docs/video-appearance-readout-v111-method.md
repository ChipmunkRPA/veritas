No population error rate, customer confidence or public screening point follows.

## Local support has a separate scope

Raw local support uses each available window's unchanged raw point. For the
candidate, replay each available window alone into the same fixed file map and
record whether it can drive that file point. This is file-head support, not a
new calibrated per-window AI probability. Keep available local diagnostics even
when another missing window makes the file inconclusive; do not label the file
original from incomplete support.

For each arm, separately report the union of flagged **sampled middle-frame
positions**: overlap with changed AI-source frames, flagged non-AI positions,
planned sampled AI positions and AI-source frames never scheduled. Context-only
changes do not become middle truth. These are frame-presence labels, not
AI-pixel masks, face identity or proof of synthesis.

Also merge overlapping/touching bounding intervals with no gap bridging.
Report continuous union IoU with the known insertion interval, mean over AI
files including zero when no supported interval is flagged, and flagged seconds
outside that interval. No new localization-success cutoff is selected. An
interval spans unsampled pictures; report its metrics separately from sparse
positions and keep unavailable-file counts visible.
