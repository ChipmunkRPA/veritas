# Independent native-mouth point and clip study calibration

This prospective stage uses only the ten fixed `confidence_cal` connected
groups, all 60 planned conditions, and the already frozen three v125 heads.
No selection or confirmation vector is scored here. Bind the successful fit,
private learned-artifact hash, complete feature/replay aggregate, new procedure,
tests, executed current-check sources and numerical package versions before
the first calibration response. All prior frozen methods and artifacts remain.

## Blind scoring and study targets

Use every v125 eligible native centre and its frozen 16/32/64-variable head.
No truth interval, mask, role or condition chooses candidate input positions.
At each actual centre, score the complete native three-picture visual descriptor
and supported cached speech summary. Generate every window of three consecutive
scored centres, requiring native gaps no larger than 80 ms. Its raw score is
their mean. Each window therefore has five-picture visual input support; retain
exact half-open native picture indices, source timestamps and before/during/after
indices. Its last display endpoint uses the previously declared constructed
terminal duration where needed, not a measured original exposure time.

For each head, independently calibrate point margins against **central-picture**
edit labels and maximum window margins against known **whole-clip** neural
provenance labels. Label attachment happens after blind selection. Ordinary
resampling/blur and unedited neural-clip context are negative point targets.
Missing scope has no margin or substituted original reading. Speech states can
depend on the whole input; these timestamps do not prove strictly local cause.

Each calibration is its own positive-slope sigmoid. Give each class half the
weight, then equal source-group, available condition and point/case weight
within class. Retain short original-only controls. Standardize its own margins
by weighted mean and standard deviation, with scale floor 0.05. Minimize mean
weighted logistic loss plus 0.01 times squared slope/intercept with L-BFGS-B,
slope in [0,50], intercept in [-50,50], initial [1,0], max 2,000 iterations,
ftol 1e-12 and gtol 1e-8. Require convergence. A reversed head can become flat;
calibration may not reverse its direction. Do not present these balanced study
probabilities as population probabilities or customer confidence. Before the
freeze, the authored balanced two-value fixture exposed a line-search stop at
gradient norm 3.56e-9 under gtol 1e-9. The declared gtol 1e-8 resolves this
floating-point stopping issue; no real calibration/test response informed it.

## Frozen research operating points and current comparator

For each head, take the maximum window score over every ready genuine control
condition within each calibration source group. All ten groups need observed
control windows. Set three internal strict-greater-than raw-margin points:
the next representable value above the largest, second-largest and third-largest
group maximum. These allow at most zero, one and two flagged calibration groups,
respectively; ties can allow fewer. Predeclare the two-group budget as the
primary comparison and publish all three settings' held-out outcomes later.
These small-panel budgets are neither a product threshold nor a promised error
rate. No operating point is adjusted after selection or confirmation results.

Run the **actual current** commercial, model-free mouth/audio correlation
adapter on every ready calibration clip, supplying the common audited dense
native YuNet face coordinates as one source track. Decode the actual clip's
soundtrack and verify its native audio origin/mapping. Decode and hash every
RGB picture the adapter requests. Capture its actual windows, source anchors,
lag profiles, explanations and segments in a private exhibit sink. Do not load
SyncNet, a landmark network or any other new model. Record unsupported or
informational/no-window outputs separately; neither is an original-file verdict.
This compares the current scoring algorithm under common recorded face inputs,
not the serving tracker's sparse sampling or full application pipeline parity.
