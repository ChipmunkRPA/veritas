## Failures retained and repaired

The initial offline-package test run rejected the already present pure
`face_interval_binding` helper under its runtime import guard. Its allowlist was
stale; `sound_event_binding` was also missing. The test now permits those two
explicitly standard-library validators and additionally blocks NumPy, Torch,
OpenCV, Transformers, FastAPI and SQLAlchemy. Separate AST checks enforce their
standard-library-only imports. All six affected offline subprocess cases pass.
No detector/quality requirement was removed.

The first full rollback attempt failed while validating unflagged older windows.
Independent six-decimal rounding produced a 1.15e-6 arithmetic discrepancy from
a valid original measurement. The original failed analysis is retained locally.
Both new and prior review records now retain exact hexadecimal float
commitments, like the existing alignment-matrix commitments. Validation checks
those exact values and the displayed rounded values separately, using 1e-12 for
exact arithmetic. The earlier approximate limit is unchanged for historical
records without exact fields. This fixes serialization without changing model
outputs, operating points or rewriting old results. A new isolated rollback
attempt then completed and matched the new mode's overall decision/score.

The original production-parity launcher is retained locally; its only subsequent
cleanup removed an unused import, and all execution-body ASTs remain identical.
The native alignment/window code did not change after the comparison.

## Enable and roll back

The repository default stays `legacy`, so a fresh checkout does not silently opt
into a new asset. With the required weights installed, set in `backend/.env`:

```dotenv
VERITAS_VIDEO_FACE_REVIEW_MODE=appearance
```

Restart the local API. `sequence` restores the earlier consecutive-feature check;
`legacy` disables both extra review adapters. Both settings retain the existing
frame-classifier/track fallback. Neither option changes historic stored results.

For a new installation with downloads intentionally enabled:

```sh
VERITAS_OFFLINE=false python -m app.cli models fetch yunet.2023mar dinov2.small opencv.sface.2021dec
```

The [third-party notices](../THIRD_PARTY_NOTICES.md) retain the Apache-2.0 source
and weight declaration. Separate source-data/personality rights and upstream
training overlap are not established by a weight license. Raw face images and
biometric embeddings are not included in the public release.
