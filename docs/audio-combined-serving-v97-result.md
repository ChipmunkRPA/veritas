# Combined audio: inference-only runtime and numerical parity

The selected global combination now has a production-module implementation
with no research-script dependency, fitting code, downloads or customer-data
persistence. Its inference bundle contains the existing complementary head and
the selected combination's own calibration, with source identifiers removed.
Learned arrays remain private. **The app still uses the current audio default.**

Under the [published procedure](audio-combined-serving-v97-protocol.md), all
**4,176 completed research records** were checked against the new inference
arithmetic. All **4,028 assessed records** matched within **2.23 × 10⁻¹⁶**
absolute probability error, below the frozen 10⁻¹² tolerance, with every
tendency unchanged. The other **148 records** remained unassessed, including
31 from final confirmation. There were no new neural calls, fitting or selection.
This is numerical serving parity on already consumed records, not new accuracy.

The reviewer verified complete original full/compact journal bindings, successful
original extraction profiles, lossless float32 features, 199-frame feature
clocks, source PCM correspondence and exact four-second windows. The
[aggregate result and resource receipt](evaluation-panels/audio-combined-serving-replay-v97.json)
bind the private records through whole-artifact hashes; individual fingerprints
and source pairings are not published.

Twenty-one authored local tests cover missing/invalid responses, integrity
failures, expired deadlines, exact source samples, evidence-window coordinates
and unnamed customer wording. Shorter/longer inputs, insufficient speech and
invalid samples cannot be padded, truncated or cleared as original. The
runtime preserves the half-window speech gate and requires exactly four seconds
of original finite float32 mono 16-kHz PCM. It does not assign confidence to
every sound in a longer file or establish background authenticity.

Actual baseline/encoder extraction parity, app registration and resource
planning, UI/PDF/JSON evidence, prepayment and rollback still need full local
qualification. The numerical replay neither executes those paths nor changes
the tradeoffs in the [held-role result](audio-combined-confidence-v84-final.md).
The protected old calibration is unchanged. Publication uses direct Git pushes;
no Actions workflow, outside outreach, real charge or GCP action occurred.
