# DailyTalkEdit source qualification

DailyTalkEdit pairs original studio dialogues with one replaced utterance
generated by CosyVoice 3. The original DailyTalk recordings use two actors
across all dialogues. Dialogue IDs support a dialogue-held test. The corpus
does not provide a speaker-held or generator-held split within its own
recordings. [DailyTalkEdit construction](https://arxiv.org/html/2602.04535v1#S4.SS1) ·
[DailyTalk recording procedure](https://arxiv.org/html/2207.01063v3#S2.SS2)

The DailyTalkEdit card declares Apache 2.0. The original DailyTalk
release describes academic use and names CC BY-SA 4.0, whose standard
terms allow commercial use subject to attribution and ShareAlike.
DailyTalk adapted scripts from DailyDialog. The original DailyDialog
page linked by the paper is parked, and a mirror of the original
distribution documents CC BY-NC-SA 4.0. The downstream card alone does
not clear those underlying rights. This review uses metadata only.
No recordings were downloaded, scored, or used for calibration.
[Pinned DailyTalkEdit card](https://huggingface.co/datasets/wsntxxn/DailyTalkEdit/blob/019911d2c3c4e4b97f4c5a5c18a4c9974de43f56/README.md) ·
[DailyTalk repository](https://github.com/keonlee9420/DailyTalk) ·
[CC BY-SA terms](https://creativecommons.org/licenses/by-sa/4.0/) ·
[DailyDialog paper](https://aclanthology.org/I17-1099/) ·
[DailyDialog mirror's terms](https://huggingface.co/datasets/roskoN/dailydialog/blob/1354edc25b185125201352b283cf9480c2fa91de/README.md)

The pinned metadata contains 2,475 distinct dialogue IDs, with no
overlap among the three splits. Each has one positive-duration edit
range, expressed in decimal seconds to at most two places. These are
annotation times rather than verified sample offsets. The matching
configuration has a target utterance index and no speaker identifier.

| Split | Dialogue IDs | Min / median / max duration (s) | Duration ≤0.8 s |
| --- | ---: | ---: | ---: |
| Train | 1,800 | 0.64 / 4.48 / 15.76 | 2 |
| Validation | 200 | 1.60 / 4.14 / 12.08 | 0 |
| Test | 475 | 1.04 / 4.48 / 11.60 | 0 |

For [named-generator confirmation](audio-melo-short-source-census-2026-11-13.md#separate-confirmation),
reserve new speakers, sessions and generator families, and verify
word-level boundaries against native samples. DailyTalkEdit supplies
no test edits in the 0.1–0.8-second band.

The following reproduces the metadata counts from the exact publisher
revision. It fetches 5.1 MB of metadata and prints only hashes and
aggregate counts. Keep the source files outside the repository.

```sh
set -e
scratch=$(mktemp -d)
rev=019911d2c3c4e4b97f4c5a5c18a4c9974de43f56
base="https://huggingface.co/datasets/wsntxxn/DailyTalkEdit/resolve/$rev/daily_talk_edit/metadata"
for file in train.jsonl val.jsonl test.jsonl modify_config_pipeline.json; do
  curl -fLsS --max-filesize 3100000 "$base/$file" -o "$scratch/$file"
done
python3 - "$scratch" <<'PY'
import hashlib
import json
import re
import sys
from decimal import Decimal
from pathlib import Path
from statistics import median

root = Path(sys.argv[1])

def read(name, digest):
    raw = (root / name).read_bytes()
    assert hashlib.sha256(raw).hexdigest() == digest
    return raw

config = json.loads(read("modify_config_pipeline.json",
                         "b4c0ee60206b8cd8fd07897aa17101ac663bcdcd5c68a804bf4475abb4a0757a"))
assert len(config) == 2475
assert all(key == row["dialog_id"] and isinstance(row["target_utterance_idx"], int)
           for key, row in config.items())
seen = set()
for split, digest in (
    ("train", "baa813dbd0819b10d7bba105d501f77be911283235d48ccd96f5a235ed054c24"),
    ("val", "82a0e607ea640f01aa8fcb1dbe6d121b616f2ac506d5a3e408996ee71c673f46"),
    ("test", "2b7284f2a7324cfb1c80ebdbb0f493e223af83cf1e2e5357ad02164325f0f685"),
):
    rows = [json.loads(line, parse_float=Decimal) for line in read(f"{split}.jsonl", digest).splitlines()]
    ids = {re.fullmatch(r"(\d+)_modified\.wav", row["filename"])[1] for row in rows}
    assert len(ids) == len(rows) and ids <= config.keys() and not (ids & seen)
    seen.update(ids)
    durations = []
    for row in rows:
        (start, end), = row["fake_region"]
        assert 0 <= start < end
        assert all(Decimal(t) == Decimal(t).quantize(Decimal("0.01")) for t in (start, end))
        durations.append(end - start)
    print(split, len(ids), min(durations), median(durations), max(durations),
          sum(value <= Decimal("0.8") for value in durations), digest)
assert seen == config.keys()
PY
```
