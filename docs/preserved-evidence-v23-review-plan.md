# External numerical review plan

Declare three separate Linux jobs before dispatch. Each archives the same
immutable public study commit and independently executes all102 frozen fitting
problems, the five video methods and their adverse checks. Use only pinned
NumPy2.2.6, SciPy1.18.1, psutil7.2.2 and Python3.12.6, one BLAS thread.

The three original v22 replicas failed their host-versus-stored bitwise
normalizer audit. These new v23 jobs test an explicitly revised audit that uses
the original stored normalizer, leaving the solver and video method unchanged.
Record actual host-normalizer drift; it is diagnostic, never an exception to
the independent KKT requirement. Preserve and report all old failures.

All three must succeed. Record every actual job/run, diagnostic and numerical
difference. No automatic retry or selection of only successful jobs. Failed
partial numerical journals/workspaces are retained as artifacts; these contain
only the reviewed public scalar package and source. Require the original study's
numeric limit1e-6 and exact source/assessment/decision counts. Iteration counts
and hashes derived from floating outputs are diagnostics, not source commitments;
the independent optimality check must still pass separately in every fit.

This tests the new implementation's portability on these inputs. It does not
repair or rewrite old failed solver runs, establish universal convergence, perform
new neural inference, validate fresh detection quality or add an outside human
reviewer. Keep serving behavior unchanged unless separate detection and full-app
admission requirements are met.
