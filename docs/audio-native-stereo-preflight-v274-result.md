# Channel-preserving input checks for noisy audio

The local preflight verified eight recorded microphone channels across four DEMAND archives. Each channel has 4,800,064 samples at 16 kHz. The result binds 64 paired three-second background excerpts, with washroom and river reserved for development and kitchen and traffic for holdout. All four recording sessions were previously used through channel one. This test adds two different recorded microphone channels from each session. [Method](audio-native-stereo-preflight-v274-method.md) · [Exact aggregate](evaluation-panels/audio-native-stereo-preflight-complete-v274.json) · [Publisher record](https://zenodo.org/records/1227121)

All five authored stereo fixtures preserved each channel’s signed PCM samples and the same 48,000-sample source clock. An explicit FFmpeg downmix matched the current production decoder byte for byte. Swapping the channels preserved the mono result, and opposite-phase pulses canceled in the mix while remaining present in both source channels. A second local run reproduced the aggregate exactly. The comparison applies to the authored native 16 kHz WAVs. No speech foreground or authenticity model was opened, and production audio still uses its existing decoder.
