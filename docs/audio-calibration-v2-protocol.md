# Audio calibration pilot v2 — prospective protocol

This bounded pilot is an offline development experiment, not a release qualification.
It has no authority to alter the serving fuser or remove an installed detector.
The first experiment and its consumed holdout remain immutable. No v2 test score
is used to select a source, fit a coefficient, or change a decision threshold.

## Cohort and rights

The target is 104 previously unused original files: 52 authentic VCTK recordings
and 52 Chatterbox outputs from the published Dictation Speech collection. The
26 donated voice identities absent from the original experiment are partitioned
deterministically into 4 fit, 12 calibration, and 10 test voices. Two distinct
passages per generated voice give 8, 24, and 20 files per class in these splits.
Authentic speakers are distinct within and across splits, with one file per
speaker. The old 160-source manifest supplies exclusions, not fitting examples.
Sources, normalized transcript strings, source URLs, speaker identities, source
byte hashes and decoded PCM hashes must not cross splits or overlap that study.
Duplicate public passage URLs are excluded even when rendition IDs differ.

## Input and scope

Seed: `chipmunk-audio-pilot-20261101-v2`. Fit, calibration, and test have separate
background recordings. Each source produces clean, noise at 5 and 15 dB, and
music at 5 and 15 dB full-window RMS SNR. Three public-domain noise recordings
per split are assigned by stable source hash; each split has a different music
piece. These are controlled additive mixtures, not natural recording conditions.
Half the sources target four seconds and half eight seconds, with no padding or
looping of speech. A pre-inference availability amendment allows an authentic
speaker assigned eight seconds to fall back to a four-second recording if no
eligible eight-second passage is available for that speaker. This avoids
selecting a different speaker merely for a long utterance; generated sources
still supply one four-second and one eight-second file per voice. Report actual
duration counts. Reject short, silent, duplicate, or provenance-incomplete
sources before scoring and log the reason. Source selection uses metadata,
duration and file identity only, never detector output. Source RMS is -20 dBFS;
a shared attenuation across the five variants prevents clipping above .98.

The exact final scoring PCM is generated by production `decode_audio`, including
signed-16-bit quantization. Production full-profile adapters choose speech
windows, apply the existing speech gates, and average their scores. Store every
window's original sample interval, score, gate outcome, and aggregate. Pin model
receipts, weights, adapter and decoder bytes, manifest, and this protocol before
inference. Both detectors run on CPU with four threads. No new weights, cloud
inference, or training of a speech network is needed. The planned cost is 520
derived inputs / 1,040 detector evaluations, with loading excluded from timings.
At most 250 MB of selected audio is intended; metadata-only parquet range reads
avoid whole-corpus downloads. Stop rather than substitute an unverified source.

## Probability fitting and separate rejection calibration

Two systems are evaluated symmetrically: the installed classifier and the new
candidate. Fit a nonnegative-slope Platt mapping on the **fit split only** using
the existing class-balanced, per-original weighted logistic objective and
Platt target smoothing based on distinct original files. The calibration split
is reserved for rejection calibration. This separation avoids estimating a
rejection distribution on the same records used to fit the probability map.
The fit cohort is small; probabilities are exploratory estimates under a 50:50
reference prior, not customer population probabilities or measured certainty.
There is no combination model, hyperparameter search, or model selection here.

For each calibration speaker/voice and class, take the worst nonconformity over
all of that identity's files and five conditions: p(AI) for authentic speech,
1-p(AI) for generated speech. An unavailable/failed condition gives +infinity
for that identity; it does not silently reduce the calibration denominator.
For a new file and proposed class c, p-value = (1 + number of calibration
identity maxima >= that file's nonconformity)/(number of identities + 1).
Include a class when its p-value is strictly greater than 0.10, ties included
in the numerator. With fewer than nine identities in either calibration class,
disable definitive decisions. Missing/invalid probability always abstains.

The probability-only baseline leans AI at p >= .80, original at p <= .20,
and is inconclusive otherwise. The guarded system additionally requires the
prediction set to contain only that leaning class. Both/barely supported/no
classes means inconclusive, not a forced conclusion. Do not clamp probability
to produce a preferred label. Rank p-values are not posterior confidence.
The 10% rejection level is a pilot choice and does not meet a 5% release target.
Any exchangeability interpretation is limited to this fixed source population;
it is not an out-of-distribution or real-world error guarantee.

## Held-out reporting and decision

Before reading test scores, save immutable fitted mappings and calibration
maxima, their source row IDs, and a development-score hash. Evaluate the frozen
test once. Report raw ranking, Brier score, log loss, probability-only and guarded
decision coverage, abstentions, false AI and false original counts/rates, and
conditional error among decisions, overall and for every condition and duration.
Keep unavailable/failed cases in operational denominators. Compare both systems
on the same input records; also provide probability metrics on their shared
assessed intersection. Use 2,000 paired stratified speaker/voice bootstrap
replicates, fixed seed 749031, carrying all files and conditions in each cluster,
for metric differences; report exact binomial descriptive bounds with explicit
cluster/sample-count limitations. Bootstrap intervals condition on the frozen
fit and calibration, and do not include their estimation uncertainty. Report
family/source composition prominently.

This pilot cannot qualify promotion: only 20 test files per class, ten generated
test voices, one generated family already observed in the earlier study, and
source-class confounding (VCTK versus donated-voice synthetic passages). It does
not establish unseen-generator generalization, multilingual/telephony behavior,
long-file calibration, or detection of partially edited speech. The existing
requirement for at least 100 fresh test originals per class across source and
generation families and acceptable confidence bounds remains in force. A better
pilot result permits preparation of a larger prospectively frozen study only.
