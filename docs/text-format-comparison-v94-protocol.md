# Fixed-model formatting response comparison

Use the [v93 prepared inputs](text-format-audit-v93-preparation.md): all 288
consumed controlled documents, 32 known source/prompt groups, five requested
views each and 800 distinct effective texts after app extraction. Source labels
and all original non-whitespace positions remain unchanged. This is a targeted
formatting stress study, not fresh-author or natural-email validation.

## Fixed methods and execution

Keep the original current passage classifier, Apache-2.0 ModernBERT encoder,
own interval head, separately fitted v7 calibration maps and genuine-only
research points unchanged. Do not fit, tune, select a new point or modify serving.
Compare the two actual methods and their mask union/intersection. These are
two pretrained backbones plus the retained head, not four independent models.
Combined masks do not receive an invented combined probability.

Bind the v93 input freeze/packet, complete prior diagnostic journal, sealed
heads/maps/points, all prior native code, new worker/runtime/tests, this protocol
and current package versions before any new model call. Publish the freeze
through a manual Git push and verify its blob before response execution.

Run eight sequential batches, 36 original documents each, with every distinct
effective view retained. CPU float32, two threads and deterministic Torch
operations match the reused native reader. Models receive only the actual text
and inference-derived token positions; source IDs, labels, recipes and view names
do not enter their input tensors. No hidden states are published or persisted.

Every unchanged original must reproduce its saved raw/calibrated proposals for
both methods, native feature and offset hashes, and actual current input-token
hash. Refuse drift before interpreting that document's reformatted responses.
The first original of each batch also receives the existing native/full-model
tap and direct current-response audit. Count all actual pretrained forwards,
including audits. Reused identical effective strings supply shared responses,
not additional independent executions.

An unsupported new view remains unassessed, with no score or cleared-text
verdict. Original-reference failure, other inference failure or changed artifacts
stop and preserve the batch. All output paths are exclusive. No implicit resume,
overwrite, automatic retry, model fallback or source substitution is allowed.

Neural stages retain the established 900-second bound, 6-GiB sampled tree RSS
and initial available RAM, 3-GiB initial disk, and 1.5-GiB running RAM/disk
reserves on project/archive volumes. The monitor loads no neural library.
Terminal status must be observed; missing live samples fail. Process-group
cleanup applies on guard/failure. RSS samples are lower bounds, not true peaks.
Do not run these neural batches alongside the active full-video source decoder.

## Source-aligned comparison

For each method, apply its existing fixed research point to its actual proposals
and project the retained non-whitespace characters to original positions. For
covered positions, record the strongest actual mapped interval response. Outside
all proposals, the response is missing; do not substitute zero or originality.
The mapped interval score has the earlier retained-source-fraction target,
not a calibrated whole-file authorship probability.

Against the unchanged original, report each view's changed-highlight documents
and known groups, added/lost AI characters, added/removed human characters,
highlight Jaccard, shared scored coverage, coverage present in only one view,
and mean/max absolute score change on shared coverage. Both empty assessed
highlights have Jaccard one by definition; that does not establish correct
authorship. Unassessed pairs do not enter empty agreement. Combined masks have
no score-change statistic. Keep all failures and coverage denominators visible.

Summaries preserve every requested view despite effective-input deduplication.
Count correlated variants as controlled related observations; do not infer
population intervals or generalization from 1,440 requests. Formatting can
change layout-dependent meaning and sentence context, so a response difference
does not by itself identify the paper's exact shortcut mechanism or a provider
watermark. Existing labels are publisher provenance, not independently adjudicated
word-level authorship.

Only aggregate results and whole-artifact hashes may be public. Text, pairings,
individual fingerprints, character annotations, response journals, features and
learned parameter values remain private. New independent sources, separately
qualified improvements and evidence/export/payment tests are still required
before any serving adoption. No outreach, Actions run, real payment or GCP work
is part of this experiment.
