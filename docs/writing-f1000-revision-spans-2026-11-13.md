# Reproducing longer writing passages from archived revisions

An independent reviewer can now rebuild nine exact English article revision pairs from first-party sources. Each pair contains two historically published excerpts from the same work and credited byline. The excerpts contain three to five paragraphs, and the chosen sentence has the same immediate neighbors in both versions. Three pairs contain a material change to the chosen sentence. In six pairs, the published revision changes other excerpt text or makes a smaller change to the chosen sentence. Both groups provide controls for future single-upload tests. The source replay ran without detectors, so it supplies source and location checks ahead of any accuracy measurement.

The fixed search covered the [Crossref F1000Research March–April 2018 catalogue](https://api.crossref.org/journals/2046-1402/works?filter=from-pub-date%3A2018-03-01%2Cuntil-pub-date%3A2018-04-30%2Ctype%3Ajournal-article&rows=300&select=DOI%2Cpublished%2Clink%2Clicense%2Ccontainer-title%2Ctype). The catalogue returned 193 records. A fixed hash order picked 28 eligible v2 records after exclusions, and the replay acquired 56 exact publisher XML versions totaling 7,288,012 bytes. Two pairs failed publisher metadata checks, one failed the byline or date check, and 16 lacked an exact qualifying passage pair. The nine admitted pairs contributed 274 exact sentence positions and model-input hashes. The earlier writing studies also used F1000Research. This panel uses fresh works from a separate catalogue slice and excludes recorded work identifiers and known credited authors from seven previous evaluation ledgers. The replay checked the admitted pairs for overlapping credited authors and exact normalized 12-word fragments across all 36 cross-work comparisons. A separate local audit found no such fragment across 468 comparisons with excerpts from three retained previous panels. Those previous excerpts stay local. The published names and historical versions establish source lineage. Individual authorship and exposure in model training remain unknown.

Both versions of every admitted work declare [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/) in publisher XML. The receipt retains DOI, source URLs, credited authors, dates, license, hashes, and derived positions. Any reuse of the publisher prose should preserve required attribution and indicate changes. The receipt contains no article excerpts, third-party figures, or generated rewrites. The source archive qualification applies to the selected text passages.

All 18 historical target positions and 146 possible sentence centers qualify under the unchanged same-paragraph and word-count geometry of the [earlier longer-article trial](writing-long-position-transfer-2026-11-12.md). The replay retained exact hashes for its two-sentence edges and three-sentence centers. None of the 329 unique proposed inputs matches any of the 878 unique measured inputs saved by the earlier trial. The source receipt records both earlier comparison points for later use without refitting. Geometry checks precede tokenizer and detector execution. These longer excerpts sit outside the current three-sentence paid-route check.

The tested minimal environment used Python 3.12.6 with `lxml==6.1.2`, `pysbd==0.3.4` and `psutil==7.2.2`. From the repository root, hydrate a new cache and compare the reconstructed receipt with the frozen one:

```sh
PYTHONPATH=backend python -B -m scripts.writing_f1000_revision_spans \
  --cache /tmp/chipmunk-f1000-spans \
  --expected docs/evaluation-panels/writing-f1000-revision-spans-2026-11-13.json
```

Repeat with `--offline` to verify the cached bytes, native positions, and input hashes without network access. The first cached acquisition and a clean independent download matched on all 56 XML hashes and yielded byte-identical receipts. The Crossref responses returned the same records in a different order, so the receipt binds the complete DOI-sorted record set. A changed publisher XML byte, missing source, or changed expected position stops verification.
