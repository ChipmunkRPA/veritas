## Defined source masks and genuine-only gate

Threshold actual source float32 responses at.5. Use8-connected components,
minimum source area `ceil(pixels/1000)`, at least one pixel. Retain at most two
components, ranked by exact mean response, then area descending, then source
y/x ascending. Every selected float32 on[.5,1] is exactly an integer multiple
of2^-24, so integer sums/rational comparisons retain every ranking bit.
Do not round means, fill bounding boxes or quantize a map to8-bit.

For each format separately, take each genuine source's maximum retained-mask
area fraction over original and ordinary inputs. Fractions are exact integers
over source pixel count. The sealed gate requires area fraction **strictly
above the second-largest of24 source maxima** and at least1/1000. This allows
at most one flagged point source, including ties. The empirical budget is not
a validated population false-alarm rate or a public confidence threshold.
Seal both complete point journals, policies, plan and freeze before diagnostics.

Each phase repeats its first input for every family/kind/format exactly. Retain
every full source float32 map and selected binary mask losslessly, with input,
geometry, actual patch and file/value hashes. Failed cases remain in the full
planned denominator; incomplete point or diagnostic phases stop qualification.
Do not overwrite/restart them or select a successful generator subgroup.
