artifact and all prior fitting/feature contracts before scoring held-out media.

## Evidence and error accounting

Attach central-picture point targets and whole-clip provenance targets only
after blind candidate scoring. For each research setting, merge overlapping
flagged **input-support** intervals on exact source clocks. Compare their union
with the known actual edit interval. Report any edit overlap, temporal union
IoU and localization at IoU at least 0.2. Report outside-edit flagged duration
as well as detections; a flag entirely outside the edit is not localization.
Keep all before/during/after native indices in the private window journal.

For the highest flagged window on each AI clip, compare its actual inspected
mouth rectangle at the central native picture with the audited changed-pixel
mask. Report ROI/mask IoU and changed-pixel coverage. This rectangle is a model
input region, **not a predicted edited-pixel segmentation or causal attribution**.
A representative centre outside the true edit receives zero overlap. The
current comparator has no equivalent ROI segmentation claim; report that metric
as unavailable instead of inventing a mask.

Count ready/unavailable inputs, assessed/unassessed ready clips, missed assessed
AI, unassessed ready AI and all ready AI without a flag separately. Report genuine
false flags both per assessed genuine clip and per ready genuine clip. Keep
ordinary resampling and both blur controls separate, alongside aligned and
320-ms-earlier neural conditions. No-score denominators are null, not zero error.
Report clip/point Brier, log loss and ten-bin ECE both unweighted and with equal
class/source/condition mass. One-class condition slices retain unweighted
reliability; binary class-balanced reliability is unavailable for that slice.

At the primary setting, compare concatenation and interaction with visual-only,
and all candidates with the current adapter. Report added/lost localizations,
added/removed genuine flags and added/lost assessed scope. Bootstrap 1,000 paired
connected-source resamples with seed 127, retaining all six variants together.
Give percentile 95% intervals for changes in detection, localization and false
alarm rates over ready inputs; separately expose assessed coverage. Ten-group
intervals are exploratory and cannot establish a population error guarantee.

## Bounded execution and adoption limits

the same frozen evaluator, heads, calibrations and points. Require successful
selection receipt/profile before confirmation. Each exclusive data-only worker
uses the unchanged qualified owned-descendant monitor outside the sandbox:
900 seconds, 1.5 GiB sampled descendant RSS, 3 GiB initial RAM/project/archive
disk and 1.5 GiB running reserves. Set numerical threads to one. A global
PyTorch hook must observe zero neural forwards. Preserve any failed attempt
without retry, overwrite or relaxed limits. Samples are not guaranteed peaks.

Publish code, complete per-condition/arm aggregates and whole-artifact journal
commitments. Keep raw media, source identities, individual media fingerprints,
native face/speech vectors, margins, learned weights and evidence traces private
on Seagate. A modest false-alarm rise is reported as a tradeoff, not an automatic
veto. Any adoption decision must still consider paired gains/losses, the weak
ten-group sample, native placement and additional-generator transfer, and the
full prepaid local app/evidence/export flow. This centred single-generator bank
alone cannot justify general replacement. No serving change, external outreach,
Actions, real charge or GCP deployment occurs in this readout.
