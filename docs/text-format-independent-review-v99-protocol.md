implementation. Do not import the scorer, extraction helpers, detector runtimes,
calibration code or scientific libraries. This is a local arithmetic and source
mapping review, not an independent model execution or outside human review.

character correspondence from actual text strings, preserving order, source

proposals, native feature/offset hashes and actual current input-token hashes.

effective view at its fixed research point. Uncovered characters remain missing;

truth, population accuracy, a provider watermark or a customer confidence score.
