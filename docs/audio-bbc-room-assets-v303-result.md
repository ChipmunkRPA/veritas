# Independent measured room input qualified

The three fixed BBC R&D WAVs matched their publisher blob identities and decoded
to 16,384 stereo samples per file at 48 kHz. The stored peak sample locations
were 293/293 for front, 283/320 for left, and 320/285 for right. A second local
readout matched byte for byte. [Exact receipt](evaluation-panels/audio-bbc-room-assets-v303.json) · [Method and license](audio-bbc-room-assets-v303-method.md)

The BBC room provides separate measured front and lateral responses for holdout
rendering. The Surrey room remains the development input. This qualification
contains no speech or detector scores.
