# Noise-reduced speech view: development result

Decision: **reject both enhancement replacements**. Keep the existing voice
detector, its calibration and its rollback option. No fresh confirmation audio
was scored and no serving confidence calculation was changed.

This is the completed result of the [frozen v4 development
protocol](audio-noise-view-v4-development.md), using already-consumed v3 data.
It is not an independent accuracy evaluation. The MIT-permitted GTCRN DNS3
checkpoint was tested as a second view of the same original recording, with
the existing commercial-permission voice classifier. Original speech windows
and timestamps were retained.

## Complete execution and scope

- 120 original files: 60 authentic and 60 generated by three voice families.
  Six conditions yielded 720 inputs; these are not 720 independent recordings.
- Five folds kept source, speaker and known prompt connections together: 60
  connected groups, with 12 original files per class in each fold.
- All 720 planned inputs have ordered receipts. 690 were assessable; 30 retained
  their original unassessed status. There were no execution failures. All four
  deterministic original-path parity checks passed. The checks occurred during
  scoring, and all passed before analysis; they did not all precede the first
  enhanced inference.
- Manifest SHA-256:
  `ccecfe4acf8db9065b71da2ac7f97536369247f634ea8bc1d2546c2b90e757c0`.
  All eight frozen implementation/protocol hashes were verified after scoring.
- Original-only, enhanced-only and combined views used the same folds and
  fitting procedure. These development fits are separate from the deployed
  guarded calibration. They are not replacement service calibrations.

## Results

The table compares original-only and combined-view development fits at the
unchanged diagnostic operating points. Correct conclusions combine both classes;
false AI means authentic speech called AI, and false original means generated
speech called original. Inconclusive includes unassessed inputs. Each condition
contains 60 authentic and 60 generated inputs.

| Condition | Correct, original / combined | False AI, original / combined | False original, original / combined | Inconclusive, original / combined |
|---|---:|---:|---:|---:|
| Clean | 115 / 115 | 0 / 0 | 0 / 0 | 5 / 5 |
| Noise, 0 dB | 82 / 64 | 1 / 1 | 12 / 2 | 25 / 53 |
| Noise, 5 dB | 96 / 77 | 0 / 0 | 9 / 1 | 15 / 42 |
| Noise, 15 dB | 108 / 100 | 0 / 0 | 4 / 0 | 8 / 20 |
| Music, 5 dB | 99 / 93 | 2 / 2 | 2 / 1 | 17 / 24 |
| Music, 15 dB | 110 / 108 | 0 / 0 | 0 / 0 | 10 / 12 |
| All 720 inputs | 610 / 557 | 3 / 3 | 27 / 4 | 80 / 156 |

On the 690 common assessable inputs, source/class-weighted Brier score improved
from 0.057960 to 0.050669 and log loss from 0.201118 to 0.171300. Lower values
indicate better probability scoring. The combined-minus-original Brier
difference was -0.007292, with a conditional grouped bootstrap interval of
[-0.011555, -0.002972]. This interval conditions on the fixed development folds
and reused backgrounds; it does not measure fresh-test or refitting uncertainty.

Despite better probability scoring, the combination lost 18 correct conclusions
in the strongest noise condition and six under strong music. It failed the
predeclared requirement to gain at least five correct conclusions in each.
Fewer errors came with substantially more inconclusive results. This does not
meet the requested improvement in useful detection.

The enhanced-only fit also failed: Brier score worsened to 0.117706 and it made
no AI-leaning calls on this panel. Better listening quality therefore did not
establish better detection. Enhancement may change forensic traces; this
experiment does not establish the mechanism responsible for the decline.

For comparison only, the unchanged guarded service reference on these consumed
inputs made 500 correct conclusions, one false AI call, no false original calls,
and 219 inconclusive results. It is intentionally reported separately from the
new development fits. The unguarded development false-original counts above
must not be attributed to the running service.

## Customer explanation and integration check

A separate wording fix removes a historical generated sentence referring to an
"80% tendency" from new inconclusive speech explanations and historical public
projections. It preserves stored source quotations, scores, calibration hashes
and uncertainty decisions. This is not an adoption of the enhancement method.

165 focused audio, public-projection and multimedia-report regression tests
passed, including a replay of the existing 1,800 consumed v3 predictions.
An isolated real-model paid-flow test on a consumed noisy authentic clip also
passed: no analysis or queue job existed before simulated Stripe payment; the
result remained inconclusive with the unchanged 0.20061 AI probability. The
15-page PDF, six evidence assets, JSON/API correspondence, source coordinates,
signature, offline package and model-name filtering were verified. API and JSON
exports contained the updated explanation; the PDF omitted the old sentence.
Its cover was visually reviewed. No real payment was made and live billing was
not bypassed or altered. These are integration checks, not fresh accuracy tests.

## Limits and next work

The source pool, backgrounds, generated families and prior responses had already
been inspected. Known identity/prompt connections are grouped, but unpublished
transcript mappings, training overlap and class/source confounding remain.
There has been no outside independent review.

Fresh-source metadata was checked separately. ElevenLabs speech with publisher
CC-BY-4.0 terms and scenario-specific commercially permitted Chatterbox dialogue
subsets are possible future sources. A VoxCPM2 corpus with explicit commercial
restrictions was excluded. Metadata inspection and a bounded archive metadata
read are not a completed fresh detection test. These unused sources must not be
consumed to rescue this rejected development approach.

The next audio comparison should target noise robustness in the detector or its
calibration directly, preserve the original recording, and include unseen
background speech as well as noise and music. Freeze the method and fresh
confirmation decision before scoring new speakers or generator sources.
