# Prospective SFace bounded-transition development comparison

7 November 2026. This compares a different face-appearance representation against the actual current raw consecutive-crop review method, using previously consumed clips with known inserted swap intervals. It is not a new identity database, a face-swap authenticity probability, a whole-clip synthetic-video detector or a lip-sync method. Whole-clip swaps can contain no detectable transition. Real face features stay private; no production/default/overall-confidence change follows development alone. GCP remains last and other modalities remain in scope.

## Fixed sources and roles

Use all 60 genuine/ordinary-edit clips from the 30 consumed v5 source groups for calibration, combining that panel's former development and test roles explicitly. Do not score the 60 v5 AI clips with SFace or use AI responses to select its point. Use all 120 consumed v6 clips from 30 different source-video groups for development: 60 swaps from InSwapper/UniFace, 30 untouched originals, and 30 lighting-change/recompression/jump-cut controls. These are no longer called fresh. Source-video metadata is disjoint across roles; common subjects and pretraining overlap remain unknown.

Before inference, verify every prepared clip byte hash, its original manifest/legacy receipt and its complete native `ffprobe` frame-clock table. No inferred/truncated clock is admitted. Original sources and prepared insert-frame digests provide temporal labels; exact face-pixel masks are not established. The dataset publisher declares CC-BY-SA-4.0; underlying video rights remain separate. No raw video redistribution is part of this release.

The frame schedule, detected largest-face selection, source-native track association and window search remain fixed. A center uses its three actual consecutive frames, with the existing cadence limit of 0.13 seconds across the triplet. The same two-coarse-sample flanks, minimum 0.52-second and maximum 2.6-second middle span, gap limit 0.55 seconds and top-twelve ordering apply. Missing/ambiguous tracks, malformed landmarks or insufficient context produce explicit unavailable scope, never a negative authenticity finding.

## Baseline and candidate

Recompute the current production DINOv2 raw-crop patch statistic using the existing YuNet weights, GenD alignment/112-pixel resize, actual production feature/window functions and fixed point 0.007326911389827726. Hash the implementation, installed runtime, weights and decoder tools. Check all current windows against the historical source-bound reference within 0.000002 feature units, with identical window coordinates/order and the same selected range/review choice. No legacy frame-classifier scores enter either representation statistic.

Both arms share the immutable historical legacy frame-classifier scores and track exhibits as fallback. Recompute their interval/peak rule from those saved native-time inputs. This holds a common component fixed; it does not claim new legacy classifier/tracker inference or a complete serving-pipeline evaluation. The baseline is current consecutive cue when above its existing point, otherwise legacy. The replacement candidate is SFace when above its own point, otherwise legacy. If the candidate cannot assess a clip or fails, preserve the entire current result. Failures still invalidate advancement.

The candidate uses the already reviewed weight-inclusive Apache-2.0 SFace checkpoint and the [passed native input/graph contract](video-v15-sface-native-runtime.md). On the same source RGB frames, convert once to BGR and use native five-landmark alignment. Each finite nonzero 128-dimensional feature is normalized in float64 before triplet averaging. Compare the average middle appearance to each flank using cosine distance. Response = smaller middle-to-flank distance minus 0.35 times the between-flank distance. The penalty is fixed from the existing method; there is no new coefficient search, photometric arm or generator-specific point. It measures a bounded appearance change and cannot prove AI editing.

For every assessed real face, retain source PTS/RGB hash, box, landmarks, exact hexadecimal alignment matrices, crop/blob hashes and private feature bytes/hash. Check native crop bytes against the independent source transcription and native input bytes against the direct channel/transposition path. Repeat native feature inference and compare a direct forward of the same graph/engine: exact repeat, maximum absolute difference 1e-4 and relative difference 1e-5. All these requirements were fixed in the prior native protocol and are not relaxed here. Complete scheduled-frame decode coverage and baseline parity are mandatory. Real feature vectors and raw face imagery are not published.

## Genuine-only matched review budget

Score the 60 genuine calibration clips first. Require complete planned IDs, no failed cases, at least 40 cases and 20 source groups with eligible candidate windows, and at least 20 eligible cases the current method did not flag. Stop if those conditions or native/current parity checks fail; do not score development. No unavailable response becomes zero.

Among those eligible currently unflagged genuine cases, take each case's maximum candidate response. The single operating point is the larger of zero and the second-largest case maximum. Apply a strict `>` comparison. This adds at most one new genuine review flag on calibration; already flagged genuine cases do not consume incremental budget. Ties can reduce the added count. No AI case or response, edit boundary, development false alarm or model publisher identity-match threshold selects this point. Publish it and its source/response hashes before development scoring. It is an empirical feature operating point, not a calibrated confidence percentage or public service screening claim.

## Frozen advancement requirements

Use all 120 planned development clips, including unassessed cases and failures. A correct localization requires the first displayed range to reach temporal intersection-over-union at least 0.30 with the known inserted interval. Compare the complete current method and complete candidate replacement with their declared fallbacks, not only a favored subset of eligible clips.

Advancement requires all planned cases accounted for, no inference failures or resource guards, all current and native parity checks passing, strictly more correctly localized swaps, no more than one additional **total** genuine/control review flag, no more than one additional ordinary-edit control flag, no lower mean edited IoU, and no loss in correctly localized count for either swap family. The false-alarm allowance concerns net counts; also publish each newly flagged/cleared genuine case and every gained/lost AI location. Report source/eligibility/status counts, misses, per-family results, and before/during/after source bindings. More abstention alone is not detection improvement.

Report paired source-group bootstrap intervals for edited IoU, localization rate and genuine review-flag rate: 5,000 draws, NumPy generator seed 20261107, keeping each source's variants together. These are descriptive consumed-panel intervals. A successful result permits a separately frozen fresh source/donor-excluded confirmation, followed by ordinary-view/PDF/JSON/name-filter/paid-flow verification before scoped local adoption. Failure retains the current check without silent point/model switching. No calibrated overall probability is inferred from an appearance distance.

## Runtime and preservation

Run model studies sequentially. Use two Torch CPU threads, one OpenCV thread, CPU SFace and the frozen local MPS DINOv2 baseline. The parent samples descendant-tree RSS every 0.25 seconds, stops above 6 GiB RSS, below 1.5 GiB available system memory or disk, or after two hours per phase. Decoded source clips have a 120-second watchdog and frame probing a 30-second watchdog. Preserve every original journal, private feature packet, guard/failure and source freeze; no overwrite or silent resume/restart. Sampled memory is a lower bound. No outside human reviewer is claimed by local or separate-machine checks.
