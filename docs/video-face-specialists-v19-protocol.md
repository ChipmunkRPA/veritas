# Video face evidence: separate local calibration and combined evaluation

Prospective consumed-source development study; no serving admission, fresh reserve,
identity recognition, lip-sync result, whole-video originality claim, or outside
human review. This follows the source-only v18 input and decoded-RGB audit.

All 648 exact prepared clips in 162 known source components are included. The
source-frame audit checks native clocks and actual RGB changes in the known edit
ranges, then refines source groups using exactly equal nonuniform sampled frames.
Four source-disjoint roles separate specialist calibration, combination fitting,
combination calibration and confirmation. Unknown people, source and pretraining
connections remain possible. These are previously consumed development sources.

Before authenticity inference, freeze code, weights, commercial licence records,
packages, decoder binaries, source hashes and all 14,256 source-coordinate units.
Each clip has fixed half-second face-crop centers and fixed consecutive triplets:
three middle centers with two before and two after. Native model inputs must match
the decoded source audit. Publisher AI labels plus actual RGB change establish
sampled source-frame presence only, never which person/face/pixels were edited.
Ordinary changes remain genuine controls. Missing inputs remain explicit.

Unchanged GenD face-crop logits are the primary view. SFace appearance transition
and DINOv2 patch-feature transition are additional views. YuNet detects faces.
Only a single visible detected face is eligible; temporal views also require
overlapping boxes on every planned input. This is geometric continuity, not
identity tracking. The declared weights have commercial-admitted MIT/Apache-2.0
records; this does not establish rights to every upstream training example.
Read-only cached assets are rehashed; there are no downloads or customer inputs.

Four arms: crop, crop plus appearance, crop plus features, all three. Each view
has a source-balanced monotone local calibration with 25 source components per
class and L2 .001. Dependent views are positive-logit maxima in one video-face
family, followed by separate source-disjoint combination fit and calibration.
Scores refer to a declared 50:50 reference prior, not customer accuracy. Missing
required observations withhold combined confidence; no missing response is zero.

All parameters and internal evaluation points are frozen before confirmation
authenticity inference. Use the same completely assessed genuine combination-
calibration components across all arms (minimum 25). Match the raw current GenD
component false-flag count, capped at floor(10% of those components). Choose
strictly greater than the sorted group maximum at rank n minus budget. Local
points similarly match the existing raw cue on the same genuine components.
Ties do not flag. This is a private evaluation rule, not a public service claim.

Report AI flags, missed AI including inconclusive cases, genuine false flags,
inconclusive rates and source/class-balanced Brier scores. Also report local
source-unit false flags and edit localization with time/frame coordinates and
IoU >= .3. Merge flagged support spans with gaps at most 550 ms for every arm and
raw reference, then compute the best merged interval's IoU. Bridged gaps are an
interval estimate, not examined pixels; sampled-frame flags are counted separately.
Correct file detection alone is not correct localization. Compare raw
existing cue arithmetic on the exact same fixed supports; do not claim this is
the complete adaptive production tracking/window selection or whole app.

Only continue an alternative if it finds more AI files with no increase in genuine
false-flag components, no coverage loss, and more correctly localized edited clips
than crop alone. Even a qualifying result still needs fresh-source and full-app
verification before promotion. A failed fit or run is retained without implicit
retry, replacement inputs or confirmation-driven threshold changes.

Native stages run sequentially: CPU YuNet/SFace, MPS float32 GenD/DINOv2, fixed
batch sizes 8/12. First eligible inputs per view/role repeat (SFace bitwise;
GenD absolute 1e-4; DINO absolute/relative 1e-4). Every SFace crop is compared
bitwise with the independent alignment transcription. Guard sampled process-tree
RSS at 6 GiB, available memory and disk at 1536 MiB, and each role at 3600 seconds.
RSS is a lower bound, not a complete accelerator memory measurement. Raw media,
geometry, alignment records, face features and frame journals stay private.
