# Unused-source native image comparison, v45

This owner-directed successor reopens the adapted localizer despite its original
per-control zero-increase rejection. It compares multiple models/settings and
actual combined masks. It does not rewrite the completed v43 calibration result.

Use the unchanged v41 plan's complete **point role: 27 photos / 24 source
components**, each with AI, original, tone and blur views. These source groups
have not been forwarded by project fitting or calibration. They now become a
development/comparison role used to select methods; do not subsequently call
them an untouched final benchmark. Diagnostic/confirmation roles remain unused.
All sources share the earlier editing family; this is not unseen-generator proof.

## Fixed paths and readouts

Native PNG encoding only; original source geometry, controls, checkpoint and
reconstruction remain unchanged. Execute three paths on every view:

1. Current native splice detector with its actual existing gate.
2. The full-source adapted localizer, final accepted update 1,278.
3. The existing FUSED detector with its existing gate, applied to the same native
   RGB input. Its loader is the unchanged v28 JPEG-baseline graph; the source is
   **not JPEG recompressed**. This tests a cross-format reference explicitly.

Retain 108 maps per path in five phases (24/24/24/24/12). Repeat the first input
of each path exactly. Total: **324 unique calls plus three repeat calls**.
Keep every failure/unavailable outcome and stop on failed phases; no retry or
overwrite. Use the pinned assets and earlier bounded-local-study permission
records. No new weight, decoder or unrestricted production-data grant is assumed.

Evaluate seven fixed source-space masks: current; FUSED reference; adapted
settings `p0.90-a0.01000`, `p0.60-a0.01000`, `p0.40-a0.00100`; and actual OR/AND
of the current mask with the strictest adapted mask. The three settings were
chosen after v43 calibration and before new source calls. No label selects a
method per input. Validate standalone mask metrics against the frozen production
reconstruction before measuring unions/intersections. No oracle best-case union.

## Measurement and selection

Useful localization retains IoU >=0.30 and edit recall >=0.50. Report every
method's group-balanced useful fraction, mean IoU, new/lost useful photographs,
empty edit masks, per-control false groups and photographs, any-control false
groups and wrongly highlighted area. Reuse v27 grouping/count definitions.
Bootstrap paired component differences with 10,000 draws, seed 20261108,
linear 2.5/97.5 percentiles. Report pointwise intervals, not simultaneous model
selection guarantees or customer confidence intervals.

There is **no automatic rejection for an increase in one error type**, and no
requirement to preserve every prior successful case. Keep all methods in the
tradeoff table, including observed dominated points. This comparison does not
admit a default or authorship probability. Choose later comparisons from this
development evidence, then freeze selected methods before final confirmation.
A missing/skipped/inconclusive check cannot become a zero mask or originality.
