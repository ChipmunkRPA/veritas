# Seven short text edit witnesses verified in official revisions

The January 2018 sample checked 12 article histories and rendered ten
exact parent–child revision pairs using 29 official API requests. Four
articles produced seven short lexical replacement windows with unchanged
context on both sides. Offline replay reproduced all counts without new
requests. [Method](text-goce-intake-v228-method.md) · [Verified counts](evaluation-panels/text-goce-intake-complete-v228.json)

Seven article histories exceeded the fixed revision limit. One other
article supplied eligible revision pairs without a qualifying short
replacement. The seven exact witnesses are candidates for source-level
rights and overlap review. That review is pending. The experiment used
only historical editorial records and text, with zero model calls.
